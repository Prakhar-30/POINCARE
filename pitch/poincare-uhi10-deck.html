Poincaré · the problem

LPs don't bleed on volatility. They bleed on direction.

Two paths with identical volatility. Only one of them costs liquidity providers anything.

Both paths take the same set of step sizes — only the order of the signs differs. The one that goes nowhere barely leaks value; the one that trends is arbitraged the whole way. That is Loss-Versus-Rebalancing: it is paid for direction, not for movement.

02
Poincaré · the insight

The fee isn't in the equation.

Milionis–Moallemi–Roughgarden–Zhang give the LVR rate exactly. One line, two consequences.

LVR ≈½ σ² · marginal liquidity

Curvature is the lever

“Marginal liquidity” is a property of the curve's shape. The fee term does not appear at all — so fee-tweaking, which most hooks do, pulls a lever the mathematics doesn't contain.

The damage is directional

Only sustained one-way moves drain LPs. So the right response is to reshape curvature asymmetrically — and only while a real trend is actually happening.

03
Poincaré · the engine

“Has a regime change begun?” is a solved problem in statistics.

It's called Quickest Change Detection, and its optimal workhorse is CUSUM (Page, 1954). Evidence accumulates; an alarm fires at a threshold.

Why that matters here

The firing moment is a data-dependent stopping time. A strong trend crosses fast; noise never does. There is no “after N blocks” to precompute — and CUSUM is Lorden minimax-optimal: provably the best possible trade-off between reacting fast and being fooled.

A scan of all 562 hooks in the UHI directory returns zero uses of CUSUM, change-point detection, SPRT or quickest detection.

04
Poincaré · the actuator

Toxic flow pays a spread. Stabilising flow pays nothing.

We shipped the safe lever, and we can show why

The obvious design — different curve depth per direction — is arb-drainable. We built it, found a buy-shallow / sell-deep round trip that empties the pool, and rewrote the asymmetry as a non-negative spread on a symmetric base: safe by construction, proven by fuzzing and a 384,000-operation invariant.

Unlike a fee, it is targeted

A symmetric fee taxes everyone on every block. Poincaré charges only the side actually taking money out of LPs, and only while the detector is confident.

Poincaré · what this unlocks

The detector is a platform, not a one-off.

Everything below is built on the same statistic — three of the four are already implemented and tested.

Self-calibrating thresholds ✓ built

Feed the CUSUM the standardised increment r/σ̂ and the thresholds breathe with the market — scale-free across pairs, no governance. Cuts LVR 29.6% on the synthetic path with no absolute calibration. Gated off until its manipulation bound is derived.

Any pair, no code change ✓ built

Point the calibration harness at another series and it re-derives σ, k and h from that pair's own returns. Every parameter is already a constructor argument.

The curvature lever — the bigger prize

The spread is the safe half of the idea. Moving depth per direction is a far stronger lever; it needs the manipulation-cost sizing that keeps it arb-safe, which is exactly the analysis the detector makes tractable.

Routing that self-selects ✓ built

The Lens quotes the true curve, so best-execution routers naturally send calm and counter-trend flow here and take toxic flow elsewhere — the LP-favourable split, as a consequence of pricing.

Why it matters beyond one pool

LVR is the largest structural tax on onchain liquidity. Every mitigation shipped so far either needs an oracle, an auction, or trusted infrastructure. This one needs nothing but the pool's own price, so it composes with any v4 pool on any chain.

And it generalises

Any hook that must decide “is this regime real?” — dynamic fees, circuit breakers, sandwich detection — can consume the same statistic instead of a fixed threshold an attacker can time.

Poincaré · manipulation

Faking a trend is negative-EV, by construction.

1

There is no countdown to game

CUSUM fires at a data-dependent stopping time. An attacker cannot precompute the block the curve flips.

2

There is no prize waiting

The spread is one-sided and non-negative on a symmetric base, so the soft side trades at exactly the constant-product price. max_soft_gain ≡ 0 — proven in the test suite.

3

Getting there costs real money

To move the statistic you must genuinely move the price, which opens an arbitrage gap others harvest. The detector samples once per block on pre-swap reserves, so an atomic flash-and-unwind feeds it nothing.

✓

All three are tested end to end, against the real PoolManager

A fake-trend round trip loses money · a single-block flash moves the detector by zero · a σ-inflation attack on the adaptive mode burns value every block.
